## Projeto em destaque

### 📊 Relatório Financeiro Automatizado

Aplicação que transforma movimentações em CSV em indicadores, gráficos e um relatório Excel formatado.

- interface web com Streamlit;
- processamento de dados com pandas;
- geração de Excel com openpyxl;
- validações e testes automatizados;
- publicação contínua a partir do GitHub.
